# CPG archives

CPG 历史资料的原始存档。文件按资料库中的目录路径保存，原始内容和文件名保持不变。

## 迁移进度

已完成 **91 / 1586 个文件**，共 5,005,733 字节。每个已完成文件均通过 GitHub 远端原始字节、大小和 SHA-256 校验，随后删除了对应资料库原件。

其余 1495 个文件仍保留在资料库中。迁移等待适用于大文件的 GitHub 上传认证；原始清单中的条目不表示全部已经上传。

- [.archive/source-inventory.json](.archive/source-inventory.json)：已确认的完整原始迁移清单及原目录路径。
